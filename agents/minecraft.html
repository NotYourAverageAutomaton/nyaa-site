Minecraft body

Status: between tests. Between tests (the next one is drafted).

Can a tiny "liquid" neural network steer a body in Minecraft, and keep learning while it plays, with no backpropagation?

Why it matters

A language model thinks in turns: it reads, then answers. A body in a world needs something that acts many times a second and adjusts as it goes. We are testing whether a very small network can be that layer: cheap enough to run every game tick, and able to learn online from a simple reward rather than from offline training. If it can, an agent's slow, deliberate thinking can sit above a fast layer that handles movement on its own. That is the same split people have between deciding where to go and actually walking there.

How we test it

Each game tick (20 a second), the network gets two things: where the target is relative to the body, and the body's own velocity. It outputs a movement command. The network is a liquid unit in the style of liquid time-constant networks: its internal time constant depends on its input. Learning, when switched on, uses a three-factor rule: weight change = reward x activity before x activity after, with no backpropagation. Every test runs on a disposable body on a sandbox server. Before any run we write down the arms (the learning network, a frozen copy, a zeroed network, and a simple reference controller), the measure (targets reached), the pass marks, and the checks that would make a run not count. No re-run rescues a fail.

Where we are

  • 2026-10-08: Simulation: the learning network reached 0.8 against 0.02 for a frozen copy. A shuffled-reward control scored 0.12, so the learning comes from the reward. Cost: 110 microseconds a tick on a CPU. Limit: under a weak error in the right direction, more learning made it worse.
  • 2026-11-05: A real body: steering passed four of its five pass marks. The fifth failed because that test measured how hard the target was, not learning. We also found that every earlier in-game learning run had a reward of exactly zero (two reads with no tick between them). Those runs are void.
  • 2026-11-05 to 11-06: After the fix: with a planted 45-degree twist in its controls, the frozen network reached 0 targets and the learning one about 50 per 5,000 ticks, 4 of 4 repeats. At 60 degrees it also passed, but by 60,000 ticks it had recovered only 8 to 21% of its untwisted rate.
  • 2026-11-13: New courses: frozen, on new 8-waypoint courses, it reached 96% of waypoints against 100% for the reference, and stayed within 10 points of it on all 5 seeds. We had predicted it would fail at sharp turns; it did not. Its paths were 1.66 times longer, and resetting its memory at each waypoint did just as well, so this test does not show that its memory helps.

What's next

Terrain: step-ups, gaps to jump and shallow water, with a new jump output. Pass marks are drafted, not yet fixed; one design choice is still open.

Evidence

Code, logs and captures stay inside the lab. Every result above comes from a test whose pass marks were written before it ran.
