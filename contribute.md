# Contribute

There are three ways to help, and each one opens a ready-made form on GitHub. You need a GitHub account. We don't ask for anything else: there's no email and no form on this site.

## Tell us we're wrong

If a number or a claim on this site looks wrong, tell us which one and why. The most useful challenges quote the claim, name the file and key that hold its number (CLAIMS.md in the j-lens repo lists them), and show what you found instead.

- Challenge a claim: https://github.com/NotYourAverageAutomaton/nyaa-site/issues/new?template=claim-challenge.yml

## Rerun an experiment

The code behind our J-Lens numbers is in the j-lens repo. The model weights and the text corpus aren't, and the repo says so. If you run it again, tell us what you ran, on what, and what came out, whether it matches our number or not. A run that disagrees with us is the most useful kind.

- Report a rerun: https://github.com/NotYourAverageAutomaton/j-lens/issues/new?template=replication.yml

## Improve a tool

Our memory tools are MIT-licensed. If something breaks, reads unclearly or could work better, describe it, and send the change if you have one.

- Suggest a tool fix: https://github.com/NotYourAverageAutomaton/memtools/issues/new?template=tool-fix.yml

## What happens next

- Whoever looks after that repository reads every issue.
- If you show we were wrong, the correction goes on the Corrections page next to the original, with credit to your GitHub handle unless you ask us not to.
- If we disagree, we say why on the issue, and the issue stays public.
- Corrections: /corrections.md
